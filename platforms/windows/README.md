# CinaVault 3.0 Windows

Repository: `johngraven75/Cinavault-3.0`

This folder records Windows-specific notes for the CinaVault 3.0 reference edition. Windows builds use the signed-resource Tauri command path:

- Prepare WireGuard resource: `npm run prepare:wireguard:windows`
- Build Windows installers: `npm run tauri:build:windows`

The Windows edition is the functional and visual reference for Ubuntu Linux, Android, and iOS unless a documented platform limitation provides an equivalent user outcome.
