# CinaVault 3.0 Ubuntu Linux

Repository: `johngraven75/Cinavault-3.0-Linux`

This folder records Ubuntu Linux-specific notes for the CinaVault 3.0 OS edition. Ubuntu builds use the Linux Tauri bundle command path:

- Build Ubuntu packages: `npm run tauri:build:linux:ubuntu`

Ubuntu Linux must keep parity with the Windows reference for navigation, metadata, poster handling, streaming, settings, remote access, and recovery behavior unless a documented Linux limitation provides an equivalent user outcome.
