# CinaVault 3.0 iOS

Repository: `johngraven75/Cinavault-3.0-iOS`

This folder records iOS-specific notes for the CinaVault 3.0 OS edition. iOS builds use the Tauri mobile command path:

- Initialize native project: `npm run ios:init`
- Build iOS edition: `npm run ios:build`

iOS must keep parity with the Windows reference for navigation, metadata, poster handling, streaming, settings, remote access, and recovery behavior unless a documented iOS limitation provides an equivalent user outcome.
